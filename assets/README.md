# Assets Directory

Place your profile picture in this directory:
- **Filename**: `profile.jpg`
- **Recommended format**: JPG or PNG (square aspect ratio, at least 400x400px)
- **Automatic detection**: Once `assets/profile.jpg` is placed here, your portfolio will immediately display it with the dual glowing neural aura ring!
- If the file is absent, the portfolio gracefully displays your cybernetic monogram avatar ("NJ") with animated node orbits.
